# 临床康复营养研究项目 (Clinical Rehab & Nutrition Project)

本项目致力于探索临床康复过程中的营养支持策略，涵盖营养风险筛查、干预路径设计以及康复预后评估的标准化文档。

---

## 📂 核心内容模块

### 1. 📋 营养风险筛查与评估 (Nutritional Screening)
- **评估量表集**：整合 NRS 2002、MNA-SF 等临床常用营养风险筛查工具的应用指南。
- **数据指标监控**：记录患者血清白蛋白、前白蛋白等关键生化指标的动态变化追踪逻辑。

### 2. 🥗 康复期营养干预路径 (Intervention Pathways)
- **围手术期营养**：针对术后康复患者的肠内营养 (EN) 与肠外营养 (PN) 序贯治疗方案。
- **特定疾病康复食谱**：包含心脑血管、肌少症等康复期患者的膳食干预脚本。

### 3. 📉 康复效果分析 (Outcome Analysis)
- **功能评估**：研究营养摄入与日常生活活动能力（ADL）评分及握力等指标的相关性。
- **R 语言统计支持**：利用 R 脚本分析不同营养干预方案对康复周期长度的影响。

---

## 🛠 应用场景
* **临床笔记备份**：整理临床轮转中关于康复营养的典型案例。
* **护理信息学实践**：将营养评估算法与临床护理决策路径相结合。
* **学术研究**：作为毕业论文或科研项目的数据预处理与逻辑框架存放地。
